# Cafe Management System

A simple **Cafe Management System** developed using **Java and MySQL** in NetBeans.

### 🛠️ Technologies

* Java
* MySQL
* JDBC
* NetBeans

### ✨ Features

* Manage cafe products
* Add, update, and delete items
* Order management
* Bill generation
* MySQL database connectivity

### 🎯 Purpose

This project demonstrates Java application development and database management using MySQL.
