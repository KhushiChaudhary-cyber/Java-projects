# University Management System

A simple **University Management System** developed using **Java and MySQL** in NetBeans.

### 🛠️ Technologies

* Java
* MySQL
* JDBC
* NetBeans

### ✨ Features

* Student management
* Faculty management
* Add, update, delete, and search records
* MySQL database connectivity

### 🚀 Purpose

This project demonstrates Java GUI development and database management using MySQL.
